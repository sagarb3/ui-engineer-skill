# Task: Create the repository `react-ui-agent-skills` (English-only Agent Skills focused on React UI + Git tooling)

You are building a clean, professional, English-only collection of Agent Skills. The primary target is **GitHub Copilot CLI**, with full support for Cursor, Codex, Claude Code, OpenCode, and other agents that support the skills / SKILL.md format.

## Core Principles (Non-Negotiable)

1. **English only** — No Chinese, Japanese, or any other language content anywhere.
2. **Isolation** — Generated code, comments, commit messages, and files must never mention or link back to this skills repository, the parent agent, or that an AI created the code. The output must look like normal human-written code.
3. **Ask when in doubt** — If anything is ambiguous, incomplete, or has multiple valid interpretations, stop and ask the user before proceeding.
4. **Git-first when straightforward** — For simple, obvious Git operations (status, add, commit with a clear message, pull, push, checkout existing branch, etc.), execute them directly. Do not over-analyze or waste tokens exploring alternatives.
5. **Trim mode when requested** — When the user explicitly asks to “trim”, “be minimal”, “ponytail”, “lazy senior”, or “ADHD mode”, apply the trimming behavior described below.
6. **No AI fingerprints** — Never add comments, commit messages, or documentation that say the code was generated by an AI, Copilot, Codex, Claude, or any agent.

Study structure and philosophy from:

## Repository Structure

## Required Skills

### 1. harness (Core)
Acts as the default operating mode. Includes:
- Prefer the smallest complete change.
- For straightforward Git commands, just run them.
- Ask the user when requirements are unclear.
- Never add AI-related comments or attribution.
- Support an optional “trim” mode that activates the principles below.

### 2. git-tooling
Specialized skill for Git operations.
- If the requested Git action is straightforward and safe, execute it immediately.
- Only analyze deeper when the operation is destructive, ambiguous, or involves history rewriting.
- Always ask before force pushes, hard resets, or deleting branches/files.

### 3. trim-mode
When activated (user says “trim”, “ponytail”, “be lazy”, “ADHD mode”, etc.):
- Follow a YAGNI-style decision ladder (inspired by ponytail): Does this need to exist? Already in codebase? Stdlib/platform? Installed dependency? One line? Minimal code.
- Output style (inspired by i-have-adhd): Lead with the next action, number steps, end with one concrete next step, no preamble/recap/closers, keep lists short.
- Still write complete, correct code — just the smallest amount that fully solves the request.
- Never cut validation, error handling, security, or accessibility.

### 4–10. UI / React Skills
Create solid English-only skills for:
- UI Design Direction
- React Component Best Practices
- Vitest + React Testing Library (behavior-focused tests)
- Accessibility for React UI
- Design System Consistency
- React UI Performance
- Component API Design

## SKILL.md Format

Each skill should contain:
- Clear frontmatter (`name`, `description`)
- When to Use
- Process / Steps
- Anti-patterns / Red Flags
- Verification criteria
- Explicit note: “Generated code must contain no AI attribution.”

## README.md Must Include

- Project description focused on React UI skills + practical Git tooling
- Installation instructions optimized for **GitHub Copilot CLI** first, then Cursor, Codex, Claude, OpenCode
- List of skills and how to activate trim mode
- Strong statement that generated code is isolated and contains no AI fingerprints

## Additional Rules for You (the agent building this repo)

- Ask me clarifying questions if any part of the structure or skill content is ambiguous.
- Keep all content in English.
- Make the skills practical and low-token.
- After creating the files, give a short summary of what was built and recommended next skills.

Start by proposing the final folder structure and the content outline of the `harness` and `trim-mode` skills, then proceed to implement everything once confirmed.
